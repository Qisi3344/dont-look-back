# 🛹 主播别回头！ / DON'T LOOK BACK

3D 追逐跑酷原型。你是一个躺在滑板上直播的方块人，后面一个骑自行车的虚构追击者正在逼近。躲避障碍，逃到安全区。所有模型由 Three.js 几何体即时生成，不使用外部图片/3D 模型素材。

## 运行

要求 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 输出到 `dist/`。

## 控制

- PC：`A/D` 或 `←/→` 转向，`空格` 刹车
- 手机：屏幕右下方左右转向和刹车
- 躲开路障，努力跑到 1800m 终点

## 已实现（v0.1 原型）

- Three.js 3D 曲折林道、树木、方块滑板人和自行车追击者
- 追击双方独立移动、速度差产生真实距离变化
- 左上角实时追踪小地图（红色追击者、蓝色玩家）
- 石子、路锥减速，垃圾桶和路障造成翻车失速
- 追击失败/抵达终点成功、重新开始
- 模拟直播弹幕、观看人数、移动端按钮

## 仍需实现

- Rapier 刚体与更可信的碰撞/翻车物理，当前是自制触发器 + 动画效果
- 自行车 AI 路线选择、障碍避让（当前只跟随道路中心运动）
- 真正有高差的坡道、分岔、桥梁和捷径
- 皮肤系统、音效、结算评级
- 自动化测试、移动端性能分析

## 美术红线

禁止 Flash 式扁平舞台伪装为 3D、禁止静态模型充当玩法。游戏必须保持可交互的三维空间、基于世界位置的追逐和真实失败判定。
