# 🛹 主播别回头！ / DON'T LOOK BACK

3D 追逐跑酷原型。你是一个躺在滑板上直播的方块人，后面一个骑自行车的虚构追击者正在逼近。躲避障碍，逃到安全区。所有模型由 Three.js 几何体即时生成，不使用外部图片/3D 模型素材。

## 运行

要求 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 输出到 `dist/`。

## 控制

- PC：`A/D` 或 `←/→` 转向，`空格` 刹车
- 手机：左滑 / 右滑变道，上滑短暂冲刺，下滑刹车（无虚拟按钮）
- 躲开路障，努力跑到 1800m 终点

## 已实现（v0.1 原型）

- Three.js 3D 曲折林道、树木、方块滑板人和自行车追击者
- 追击双方独立移动、速度差产生真实距离变化
- 左上角实时追踪小地图（红色追击者、蓝色玩家）
- 石子、路锥减速，垃圾桶和路障造成翻车失速
- 追击失败/抵达终点成功、重新开始
- 模拟直播弹幕、观看人数、移动端滑动操作

## v0.4.3 · 三车道固定变道

- 参考地铁跑酷的离散变道方式，手机左右滑一次只移动一条车道：[-3.4m, 0, +3.4m]，单步 3.4 米，与滑动手指的长度无关。
- 手机滑动识别在手指移动达阈值时立即触发，不再等到手指离屏；一个手势最多只触发一次，可以迅速连续进行两次变道。
- 车道过渡约 0.14 秒完成 95%，并具有帧率无关的指数缓动与中途反向能力。
- PC A/D 和左右方向键统一为按一次换一条车道；保留空格刹车、上滑冲刺与下滑刹车。
- 出发剧情后的加速阶段也可进行车道控制，原有追逐、结算、地图和换装不变。
