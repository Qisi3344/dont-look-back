# 🛹 主播别回头！ / DON'T LOOK BACK

3D 追逐跑酷原型。你是一个躺在滑板上直播的方块人，后面一个骑自行车的虚构追击者正在逼近。躲避障碍，逃到安全区。所有模型由 Three.js 几何体即时生成，不使用外部图片/3D 模型素材。

## 运行

要求 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。`npm run build` 输出到 `dist/`。

## 控制

- PC：`A/D` 或 `←/→` 转向，`空格` 刹车
- 手机：屏幕右下方左右转向和刹车
- 躲开路障，努力跑到 1800m 终点

## 已实现（v0.1 原型）

- Three.js 3D 曲折林道、树木、方块滑板人和自行车追击者
- 追击双方独立移动、速度差产生真实距离变化
- 左上角实时追踪小地图（红色追击者、蓝色玩家）
- 石子、路锥减速，垃圾桶和路障造成翻车失速
- 追击失败/抵达终点成功、重新开始
- 模拟直播弹幕、观看人数、移动端按钮

## v0.3 姿势与直播设备修复

- 自行车追击者整体朝向修正：自行车车头、把手、骑车人都面向道路前进的 +Z 方向；骑车人新增朝向前方的面部特征。
- 主播保持朝道路前方移动，但脚朝前、头朝追击者（镜头）；真正仰躺于滑板。
- 右臂两段式弯曲：右肘向外、右手置于脑后；头部略微抬起，靠近追击者时继续抬头回望。
- 左臂放松沿身体摆放；直播手机通过双段固定支架连接滑板，竖屏显示 LIVE 与聊天 UI。
- 正常镜头更靠近角色，危险时自动拉远以便观察追击者。
- 新增空间朝向的自动测试：`npm test`。

## v0.3.1 仰躺修正（根据玩家视频截图）

- 修复上一版误把面部特征放在头部前面（-Z 面）、且头顶放了整块头发导致从追踪镜头看着像趴下的错误。
- 主播背部贴板，**脸、眼睛、鼻子、嘴巴全部朝 +Y（天空）**，头微微往镜头方向（-Z）抬；右手仍枕在脑后。
- 移除盖住整张脸的头发顶盖，改成脑后和脸侧发型；逼近时继续朝追击方向抬头。
- 保留直播手机、正常骑行的追击者和游戏核心追逐机制。

## 美术红线

禁止 Flash 式扁平舞台伪装为 3D、禁止静态模型充当玩法。游戏必须保持可交互的三维空间、基于世界位置的追逐和真实失败判定。
